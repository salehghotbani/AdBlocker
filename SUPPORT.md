# Support AdBlocker

AdBlocker and every blocking feature are free. The project focuses on targeted fixes for Persian websites alongside listed ad/tracker hosts. Voluntary support helps maintain filters, reproduce page issues and test browser compatibility; it never buys an advertising exception or unlocks a feature.

The extension's **Support this free project** link opens a bundled local page. Financial support controls appear only after the creator's real public receiving details are configured in [config/support.json](config/support.json). Until then, financial support is unavailable; no example address is shown as a payment destination.

To configure cryptocurrency support, the creator supplies the asset symbol, exact network and their own public Receive address. Do not commit a recovery phrase, private key, wallet password or exchange API key. Recommended initial scope is small: at most a couple of clearly labeled asset/network pairs. The page does not connect a wallet, request a signature, construct/send a transaction or detect payment. It offers explicit address copy with manual fallback. Network fees apply and public blockchain transfers may be visible to others.

Build validation checks basic address format and supported network identifiers, not ownership or blockchain checksum/token authenticity. Verify all receiving details independently before publication. The current configuration is authoritative; do not copy documentation examples into a live payment destination.

Other ways to help:

- [Report a missed ad or broken page](https://github.com/salehghotbani/AdBlocker/issues), using a public URL and screenshots with private information removed.
- Improve filters or submit a reproducible test.
- Share the source project or the verified store listing once published.
