# بررسی زندهٔ سازگاری سایت‌ها — ۲۰۲۶/۱۰/۲۹

**فارسی** | [English](SITE-COMPATIBILITY.md)

نتیجهٔ بررسی ۲۱ دامنه این است که نسخهٔ فعلی همهٔ تبلیغات همهٔ سایت‌های مشهور را حذف نمی‌کند. فهرست و جزئیات کامل در [گزارش انگلیسی](SITE-COMPATIBILITY.md) و [دادهٔ خلاصه‌شده](SITE-AUDIT-2026-10-29.json) ثبت شده است. این نمونه شامل سایت‌های مشهور جهانی، چند ناشر ایرانی و سایت‌های گزارش‌شدهٔ کاربر است؛ ادعای رتبه‌بندی دقیق ۲۱ سایت پربازدید ایران یا درصد موفقیت عمومی ندارد.

| گروه | نتیجه |
| --- | --- |
| Soft98 | مشکل حذف‌شدن محتوا با پیام تشخیص افزونه بازتولید و در نسخهٔ ۱.۶.۱ اصلاح شد. صفحهٔ اصلی و یک مطلب بررسی شدند. |
| ورزش۳ و زومیت | بنرهای مستقیم همچنان دیده می‌شوند. در زومیت صرفاً دو درخواست ردیابی مسدود شد؛ این حذف بنر نیست. |
| دیجیاتو، عصرایران، تابناک و آپارات | در صفحات بررسی‌شده درخواست ردیابی مسدود شد؛ حذف کامل تبلیغات یا تبلیغ داخل ویدیوی آپارات تأیید نشده است. |
| نمناک | درخواست‌های یکتانت و ردیابی مسدود شدند؛ پوشش تمام جایگاه‌ها اثبات نشده است. |
| دیجی‌کالا و BBC | مسدودسازی صریح شبکه مشاهده نشد. معرفی محصول را خودکار تبلیغ قابل حذف حساب نکردیم. |
| Yahoo، CNN و Weather | تعدادی از سرویس‌های تبلیغ/اندازه‌گیری مسدود شدند؛ فضای خالی یا پنجرهٔ رضایت باقی می‌ماند. پشتیبانی کامل نیست. |
| W3Schools | جایگاه‌های شناخته‌شده جمع شدند و درس باقی ماند؛ همهٔ معرفی‌های داخلی یا منوی دوره‌ها تبلیغ محسوب نمی‌شوند. |
| YouTube | درخواست‌های DoubleClick مسدود شدند. یک ویدیوی عمومی در هر دو حالت حدود ۸ ثانیه پخش شد و در هیچ حالت تبلیغ ویدیویی دیده نشد؛ بنابراین حذف تبلیغ داخل ویدیو هنوز تأیید نشده است. |
| Google، Reddit و X | کپچا، انسداد امنیتی شبکه یا خطای دسترسی مانع ارزیابی معتبر شدند. |
| Facebook، Instagram و TikTok | بدون حساب فقط صفحهٔ ورود/ابتدایی دیده شد؛ تبلیغات فید بررسی نشده‌اند. |

تست با Edge واقعی در پروفایل جداگانه و محافظت خاموش/روشن انجام شد. ورود به حساب، دورزدن کپچا و پذیرش کلی ردیابی انجام نشد. در بررسی تکمیلی W3Schools و Weather فقط گزینهٔ صریح رد کوکی انتخاب شد. خطای شبکه، درخواست ردیابی یا نبود تبلیغ به معنی حذف موفق تبلیغ نیست. دادهٔ عمومی شامل کوکی، هدر، IP، متن کامل صفحه یا اسکریپت سایت نیست.

علت مشکل Soft98 این بود که سایت پنهان‌شدن جایگاه با `display:none` را تشخیص می‌داد و محتوای اصلی را جایگزین می‌کرد. صرفاً پنهان‌کردن پیام کافی نبود. اکنون فقط جایگاه‌های تأییدشده به‌صورت عمودی جمع می‌شوند و چیدمان داخلی‌شان برای عملکرد سایت حفظ می‌شود. کد سایت و API مرورگر تغییر نکرده، مجوز جدیدی اضافه نشده و فیلتر شبکه فعال می‌ماند.

در مقایسهٔ زنده، شش توضیح نرم‌افزار صفحهٔ اصلی و دو بخش توضیح مطلب بدون تغییر و قابل مشاهده ماندند. پنل دانلود و تبدیل لینک به نشانی واقعی هنگام تعامل سالم بود؛ فایل نرم‌افزاری دانلود یا اجرا نشد. این نتیجه مربوط به دو صفحه و رفتار فعلی سایت است و تضمین همهٔ سامانه‌های تشخیص افزونه نیست. تست‌های DOM، Chromium و Firefox نیز حفظ محتوا، هندسهٔ فرزندان، شمارنده و بازیابی دقیق استایل را بررسی می‌کنند.

برای تکرار، دستورهای [گزارش انگلیسی](SITE-COMPATIBILITY.md#reproduce) را اجرا کنید. بررسی زنده از CI جداست، چون تبلیغ، شبکه و محدودیت منطقه تغییر می‌کنند. [گزارش تست](TESTING.fa.md).
