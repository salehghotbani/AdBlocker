# گزارش بررسی نسخهٔ ۱.۰.۰

**فارسی** | [English](TESTING.en.md)

این گزارش آخرین وضعیت اجرای محلی با Node.js 24.19.0 و Chromium 154.0.8037.57 را ثبت می‌کند؛ سبزبودن CI یا اجرای کامل روی تمام مرورگرها و سایت‌های واقعی از آن نتیجه نمی‌شود.

| بررسی | وضعیت |
| --- | --- |
| نصب وابستگی‌ها با lockfile | پاس شد؛ `npm ci` |
| بررسی نحو ۱۱ فایل JavaScript و لینک‌های محلی ۱۳ فایل Markdown دوزبانه | پاس شد؛ `npm run check` |
| ساخت خروجی سه مرورگر و ZIP | پاس شد؛ `npm run package` |
| سیزده تست واحد تنظیمات، worker، URL و توقف یک‌باره | پاس شد؛ `npm test` |
| چهار تست خروجی، آیکون، قواعد و ZIP | پاس شد؛ `npm run test:dist` |
| تست حفظ محتوا و رابط فارسی در Chromium | پاس شد؛ `npm run test:dom` |
| اعتبارسنجی Firefox با web-ext 10.8.0 | پاس شد؛ صفر خطا، صفر هشدار، صفر notice |
| نصب واقعی افزونه و مسدودسازی شبکه در Chromium | مسدود توسط سیاست مدیریتی؛ دستور اجرا شد و با کد خروج ۱ خاتمه یافت |
| اجرای واقعی Firefox و Edge | اجرا نشده؛ مرورگرها در این محیط نصب نیستند |

## دامنهٔ تست‌ها

تست‌های واحد از APIهای شبیه‌سازی‌شده استفاده می‌کنند. تست DOM اسکریپت و رابط واقعی را در صفحهٔ Chromium اجرا می‌کند اما ارتباطات افزونه شبیه‌سازی می‌شود. تست توزیع، تنظیمات Manifest V3، وجود فایل‌های ارجاع‌شده، مطابقت خروجی با سورس، مستندات لایسنس، ساختار PNG، قواعد شبکه و صحت فایل‌های ZIP را بررسی می‌کند.

تست `test:browser` نیاز به اجازهٔ نصب unpacked دارد و در صورت شروع‌نشدن worker با خطا متوقف می‌شود؛ اجرای بدون افزونه را موفق گزارش نمی‌کند. سیاست‌های مدیریتی محیط تغییر داده نمی‌شوند.

تست‌های جدید، تفاوت مسیر و query، بازیابی استایل برای URL مستثنا، توقف فقط در یک تب، reload خودکار اول، انقضا در reload بعدی، ناوبری SPA، بسته‌شدن تب، رد پیام غیرمجاز و بازیابی وضعیت پس از شروع دوبارهٔ worker را پوشش می‌دهند. تست کامل نصب نیز برای مسیرهای مختلف و توقف یک‌باره گسترش یافته است؛ نتیجهٔ شبکهٔ واقعی همچنان به محدودیت محیط وابسته است.

پیام مرورگر این محیط: `Loading of unpacked extensions is disabled by the administrator`. بنابراین نتیجهٔ مسدودسازی واقعی درخواست‌ها تأیید نشده است. در کنار اعتبارسنجی موفق، web-ext برای بررسی خودکار به‌روز بودن خودش پیام نداشتن دسترسی به مسیر تنظیمات کاربر می‌دهد؛ این پیام متعلق به updater ابزار است و شمارندهٔ اعتبارسنجی افزونه صفر خطا و صفر هشدار است. هنگام اجرا، کش npm به مسیر قابل‌نوشتن تنظیم شده است؛ `.npmrc` نیز برای اجراهای بعدی کش محلیِ ignoreشده تعریف می‌کند.

## اجرای دوباره

دستورها در [CONTRIBUTING.md](../CONTRIBUTING.md) هستند. workflow در `.github/workflows/ci.yml` پس از push همین بررسی‌ها، از جمله تست کامل Chromium، را روی GitHub Actions اجرا می‌کند. نتیجهٔ آن باید جداگانه مشاهده شود.
