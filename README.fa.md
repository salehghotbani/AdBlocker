# AdBlocker

<img src="docs/images/logo.png" width="80" height="80" alt="لوگوی AdBlocker">

**فارسی** | [English](README.md)

افزونهٔ مسدودسازی تبلیغات و ردیاب‌ها برای Chrome، Edge و Firefox، با رابط انگلیسی و بدون جمع‌آوری تاریخچه یا محتوای صفحات.

## امکانات

- ده زبان قابل انتخاب با پیش‌فرض انگلیسی، چیدمان راست‌به‌چپ، فونت محلی Shabnam برای فارسی/عربی و Inter برای زبان‌های لاتین؛ بدون دریافت فونت از اینترنت. زبان عبری اضافه نشده است. [جزئیات زبان‌ها](docs/LANGUAGES.md). مرور خصوصی پشتیبانی نمی‌شود.
- تمام قابلیت‌های مسدودسازی رایگان‌اند؛ [حمایت داوطلبانه](SUPPORT.md) قابلیت یا استثنای تبلیغاتی نمی‌خرد.
- [بسته‌های مخصوص فروشگاه و راهنمای ارسال](store/SUBMISSION.md) با متن معرفی انگلیسی/فارسی و تصاویر آماده می‌شوند. انتشار تأییدشدهٔ فروشگاهی هنوز ادعا نشده است. نسخهٔ فروشگاهی از خود مرورگر به‌روز می‌شود و با بستهٔ نصب دستی GitHub متفاوت است.
- شمارندهٔ زندهٔ درخواست‌های مسدودشده و جایگاه‌های تبلیغاتی مخفی‌شده، همراه با عدد درخواست‌ها روی آیکون افزونه. این دو عدد جدا هستند؛ چند درخواست ممکن است مربوط به یک تبلیغ باشند. شمارش جایگاه‌ها فقط برای سند اصلی صفحه است؛ مقدار ناموجود با خط تیره نمایش داده می‌شود و تاریخچه ذخیره نمی‌شود.
- [مدیریت محدود تبلیغات YouTube](docs/YOUTUBE.fa.md): پنهان‌سازی و بی‌صداکردن تبلیغ تأییدشده، استفاده از Skip و بازگرداندن تنظیمات پخش. تبلیغ واقعی پیش از ویدیو مشاهده شد؛ تست واقعی میان ویدیو هنوز کامل نیست.
- مسدودسازی درخواست‌های شخص‌ثالث به ۱۵۶ میزبان مشخص، اسکریپت‌های تبلیغاتی و جایگاه‌های تبلیغ Soft98 و W3Schools.
- پنهان‌سازی جایگاه‌های تبلیغ ثابت و پویا، با حفظ فرم‌ها و پخش‌کننده‌ها.
- روشن/خاموش‌کردن، استثنای سایت یا URL، توقف یک‌بارهٔ صفحه و حالت روز/شب.
- نمایش خاکستری رابط هنگام توقف محافظت روی سایت یا صفحه، با حفظ انتخاب روز/شب.
- بازخوانی خودکار همین صفحه پس از تغییر وضعیت محافظت؛ بدون نیاز به تأیید دوباره.
- در نسخهٔ نصب دستی: بررسی به‌روزرسانی و بررسی خودکار هر ۳ روز با اعلان و لینک GitHub؛ نسخهٔ فروشگاهی از خود مرورگر به‌روز می‌شود.

## نتیجهٔ آزمون

نتیجهٔ ثبت‌شده در [Turtlecute](https://adblock.turtlecute.org/) با Edge در ۲۰۲۶/۱۰/۲۸:

| بخش آزمون | نتیجه |
| --- | --- |
| کل آزمون، طبق گزارش سایت | **۱۰۰٪**؛ ۱۳۲ مورد از ۱۳۲ مورد |
| دامنه‌ها، طبق گزارش سایت | ۱۰۰٪؛ ۱۲۸ مورد از ۱۲۸ مورد |
| پنهان‌سازی ثابت و پویا | ۱۰۰٪؛ ۲ مورد از ۲ مورد |
| اسکریپت‌های تبلیغاتی | ۱۰۰٪؛ ۲ مورد از ۲ مورد |

رخدادهای مرورگر، مسدودسازی ۱۲۹ درخواست را تأیید کردند و دو تست پنهان‌سازی نیز موفق بودند. یک دامنهٔ دیگر به‌علت timeout در امتیاز سایت محسوب شده است؛ این مورد مدرک مسدودسازی افزونه نیست. درصدها مربوط به همین آزمون‌اند، نه همهٔ سایت‌ها یا مرورگرها. [گزارش کامل و نتایج CI](docs/TESTING.fa.md)

[بررسی زندهٔ ۲۱ دامنهٔ مشهور](docs/SITE-COMPATIBILITY.fa.md) پوشش ناقص را هم نشان می‌دهد: بنرهای مستقیم ورزش۳ و زومیت باقی مانده‌اند و نسخهٔ ۱.۷.۰ [مدیریت محدود تبلیغات YouTube با گزارش نتیجه و محدودیت‌ها](docs/YOUTUBE.fa.md) را اضافه می‌کند. نسخهٔ ۱.۶.۱ مشکل مشاهده‌شدهٔ حذف محتوا با پیام تشخیص افزونه در Soft98 را اصلاح می‌کند.

## نصب

از [آخرین Release](https://github.com/salehghotbani/AdBlocker/releases/latest)، ZIP مرورگر خود را دانلود و استخراج کنید.

| مرورگر | روش نصب |
| --- | --- |
| Chrome 120+ | در `chrome://extensions`، گزینهٔ **Developer mode** و سپس **Load unpacked** را بزنید و پوشهٔ استخراج‌شده را انتخاب کنید. |
| Edge 120+ | همین مراحل را در `edge://extensions` انجام دهید. |
| Firefox 140+ | در `about:debugging#/runtime/this-firefox`، گزینهٔ **Load Temporary Add-on** و سپس `manifest.json` را انتخاب کنید. |

بسته‌ها بدون امضا هستند؛ نصب Firefox موقت است و با بستن مرورگر حذف می‌شود. پس از نصب یا به‌روزرسانی، صفحه‌های باز را دوباره بارگذاری کنید.

برای به‌روزرسانی، تمام فایل‌های ZIP از جمله `manifest.json` را جایگزین و **خود افزونه را در `chrome://extensions` یا `edge://extensions`، Reload کنید** تا مجوزها اعمال شوند. اگر API زمان‌بندی یا اعلان در دسترس نباشد، محافظت و بررسی دستی فعال می‌مانند و پنجرهٔ افزونه محدودیت را توضیح می‌دهد.

همهٔ تبلیغات، به‌ویژه تبلیغات داخل ویدیو، حذف نمی‌شوند. اگر سایتی درست کار نکرد، از استثنای سایت یا صفحه استفاده کنید. [نتایج و محدودیت‌های تست](docs/TESTING.fa.md)

## ساخت از سورس

نیازمندی‌ها: Node.js 20+ و Python 3 برای ZIP.

```sh
npm run build
npm run package
```

خروجی‌ها در `dist/chrome`، `dist/edge` و `dist/firefox` و ZIPها در `dist/` ساخته می‌شوند. [راهنمای توسعه و تست](CONTRIBUTING.fa.md)
