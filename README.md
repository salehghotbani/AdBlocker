# AdBlocker

**فارسی** | [English](README.en.md)

![License: MIT](https://img.shields.io/badge/license-MIT-green)

افزونهٔ Manifest V3 برای Chrome، Edge و Firefox با رابط فارسی؛ بدون سرور، ردیابی، دریافت تاریخچه یا ارسال دادهٔ مرورگر به بیرون.

## تصویر رابط

<p align="center"><img src="docs/images/popup.png" width="350" alt="رابط فارسی AdBlocker با کنترل عمومی، استثنای سایت و بارگذاری مجدد"></p>

تصویر از رندر رابط واقعی در تست مرورگر با سایت و ارتباطات آزمایشی گرفته شده است؛ تأیید نصب کامل افزونه محسوب نمی‌شود.

## قابلیت‌ها و محدودیت‌ها

- مسدودسازی درخواست‌های شخص ثالث به ۶۰ دامنهٔ تبلیغات و ردیابی مرتبط، با API بومی `declarativeNetRequest`؛ شامل تعدادی از مسیرهای سرویس‌دهی تبلیغات ایرانی.
- پنهان‌کردن جایگاه‌های مشخص Google Ads؛ پشتیبانی از عناصر تبلیغاتی که پس از بارگذاری صفحه اضافه می‌شوند.
- حفظ عنصرهای `main`، `article`، عنوان اصلی، فرم و پخش‌کننده و ظرف‌هایی که این عناصر را در خود دارند؛ بدون حذف عمومی `.banner`، `.sponsored` یا عناصر حاوی واژهٔ «تبلیغ».
- روشن/خاموش‌کردن عمومی، استثناکردن هر سایت و زیردامنه‌هایش، پاک‌کردن استثناها و ذخیرهٔ تنظیمات روی همین دستگاه.
- توقف یک‌باره برای یک صفحه در یک تب، و استثنای دائمی برای یک URL مشخص.
- با خاموش‌کردن، استایل قبلی عناصر برمی‌گردد؛ برای بازیابی درخواست‌هایی که قبلاً مسدود شده‌اند باید صفحه را دوباره بارگذاری کنید.

**حذف تمام تبلیغات و حفظ تمام محتوای اصلی روی همهٔ سایت‌ها تضمین‌پذیر نیست.** این نسخه عمداً محافظه‌کار است. تبلیغات هم‌دامنه، تبلیغات ادغام‌شده در ویدیو (از جمله برخی تبلیغات YouTube)، تبلیغات بومی و سرویس‌های خارج از فهرست ممکن است باقی بمانند. سایت‌های دارای تشخیص مسدودکننده ممکن است نیاز به استثنا داشته باشند. دامنه‌ها به‌صورت محلی نگهداری می‌شوند و فهرست به‌طور خودکار از اینترنت دریافت نمی‌شود. این پروژه پیاده‌سازی کامل EasyList/uBlock Origin نیست.

## ساخت

Node.js نسخهٔ ۲۰ یا بالاتر لازم است. خود افزونه و مرحلهٔ ساخت هیچ وابستگی اجرایی ندارند:

```sh
git clone https://github.com/salehghotbani/AdBlocker.git
cd AdBlocker
npm run build
```

خروجی‌ها در `dist/chrome`، `dist/edge` و `dist/firefox` ساخته می‌شوند. برای ZIP با Python 3:

```sh
npm run package
```

فایل‌های `dist/adblocker-*-1.0.0.zip` بستهٔ بدون امضا هستند.

## نصب محلی

### Chrome / Edge (نسخهٔ ۱۲۰ به بالا)

۱. در Chrome به `chrome://extensions` یا در Edge به `edge://extensions` بروید.
۲. **Developer mode** را روشن کنید.
۳. **Load unpacked** را بزنید و پوشهٔ `dist/chrome` یا `dist/edge` را انتخاب کنید.
۴. افزونه را روی نوار ابزار سنجاق کنید و صفحه‌های باز را دوباره بارگذاری کنید.

### Firefox دسکتاپ (نسخهٔ ۱۴۰ به بالا)

۱. به `about:debugging#/runtime/this-firefox` بروید.
۲. **Load Temporary Add-on** را انتخاب کنید.
۳. فایل `dist/firefox/manifest.json` را باز کنید.

نصب موقت با بستن Firefox از بین می‌رود. نصب دائمی به امضای Mozilla نیاز دارد؛ انتشار در فروشگاه‌های هر سه مرورگر کار جداگانه‌ای است و در این پروژه انجام نشده است. نسخهٔ Android حداقل ۱۴۲ در manifest اعلام شده، اما روی Android آزمایش نشده است.

## توقف موقت یا دائمی یک صفحه

در پنجرهٔ افزونه، بخش «همین صفحه» نشانی جاری را نشان می‌دهد:

- **توقف این بار و بارگذاری مجدد:** فقط همین تب برای یک نمایش صفحه مستثنا می‌شود. صفحه یک بار خودکار reload می‌شود تا منابع مسدودشده دوباره دریافت شوند. reload بعدی، رفتن به نشانی دیگر، بستن تب یا بستن مرورگر توقف را تمام می‌کند. تب‌های دیگر مستثنا نمی‌شوند. «ادامهٔ مسدودسازی و بارگذاری مجدد» توقف را زودتر پایان می‌دهد.
- **فعال برای همین URL:** خاموش‌کردن این کلید، نشانی جاری را دائماً استثنا می‌کند؛ بعد از reload و بازکردن دوبارهٔ مرورگر هم باقی می‌ماند. روشن‌کردن کلید یا «پاک‌کردن استثناهای URL» آن را حذف می‌کند. برای اعمال کامل تغییرات شبکه، صفحه را دوباره بارگذاری کنید.

تطبیق URL شامل پروتکل، میزبان، پورت، مسیر و پارامترهای query است؛ بزرگی و کوچکی حروف مسیر و ترتیب query اهمیت دارد. بخش `#fragment` حساب نمی‌شود، چون قواعد شبکهٔ مرورگر آن را نمی‌بینند. استثنای یک URL شامل مسیرهای دیگر آن سایت نمی‌شود. حداکثر ۲۰۰ استثنای URL با طول هر URL تا ۱۵۰۰ نویسه پشتیبانی می‌شود؛ نشانی دارای نام کاربری/رمز عبور پذیرفته نمی‌شود. توقف عمومی و استثنای کل سایت همچنان بر کنترل صفحه اولویت دارند.

در سایت‌هایی که بدون بارگذاری سند، مسیر را تغییر می‌دهند، کنترل ظاهری به‌روزرسانی می‌شود؛ برای تضمین اعمال کامل قواعد شبکه، reload کنید. URLهای انتخاب‌شده ممکن است پارامتر حساس داشته باشند؛ فقط وقتی می‌خواهید همان نشانی به‌عنوان استثنا روی دستگاه ذخیره شود، از گزینهٔ دائمی استفاده کنید.

## تست

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm run package
npm test
npm run test:dist
npm run test:dom
npm run test:browser
```

- `npm test`: سیزده تست تنظیمات، بازیابی وضعیت worker، قواعد استثنا، تطبیق دقیق URL، انقضای توقف موقت، جداسازی تب‌ها، صف درخواست‌ها و ردکردن تغییرات غیرمجاز. APIهای مرورگر در این تست‌ها شبیه‌سازی شده‌اند.
- `test:dist`: چهار تست برای manifestهای تولیدشده، فایل‌های ارجاع‌شده، مطابقت با سورس، لایسنس، آیکون‌های PNG، قواعد مسدودسازی و صحت ZIPها.
- `test:dom`: مرورگر واقعی Chromium با رابط ارتباطی شبیه‌سازی‌شده؛ حفظ مقاله/فرم/ویدیو/iframe سالم، مخفی‌سازی پویا، بازگرداندن استایل‌ها و تعامل با پنجرهٔ فارسی را بررسی می‌کند. این تست مسدودسازی شبکه را آزمایش نمی‌کند.
- `test:browser`: تست کامل با نصب واقعی افزونه؛ باید درخواست تبلیغاتی واقعاً مسدود شود و با استثناکردن سایت یا خاموش‌کردن افزونه دوباره مجاز شود. پاسخ‌های خارجی fixture محلی هستند و هیچ سایت تبلیغاتی فراخوانی نمی‌شود. نیاز به مرورگری دارد که نصب unpacked در آن مجاز باشد.

مسیر پیش‌فرض مرورگر تست `/usr/bin/chromium` است. روی سیستم دیگر، متغیر `CHROMIUM_PATH` را به فایل اجرایی Chrome/Chromium تنظیم کنید. Playwright فقط وابستگی توسعه و تست است و داخل افزونه قرار نمی‌گیرد.

نتایج اجرا و محدودیت‌های تست در [گزارش تست](docs/TESTING.md) ثبت می‌شوند. CI نیز بعد از push، ساخت، تست واحد، تست DOM، نصب واقعی افزونه در Chromium و اعتبارسنجی Firefox را اجرا می‌کند. سبزبودن CI را باید از نتیجهٔ همان اجرا بررسی کرد؛ این مستندات به معنی پاس‌شدن CI نیست.

برای اعتبارسنجی خروجی Firefox:

```sh
npm run lint:firefox
```

## مجوزها و حریم خصوصی

دسترسی HTTP/HTTPS برای اجرای قواعد و یافتن جایگاه‌های تبلیغ در صفحات لازم است. `storage` تنظیمات و استثناهای انتخاب‌شدهٔ کاربر را محلی نگه می‌دارد؛ `activeTab` برای نمایش سایت فعلی پس از کلیک کاربر و `webNavigation` برای پایان توقف موقت هنگام جابه‌جایی صفحه استفاده می‌شود. تاریخچهٔ مرور جمع‌آوری نمی‌شود. هیچ تحلیل‌گر، کلید API، سرور یا کد از راه دور وجود ندارد. پیام تغییر تنظیمات فقط از صفحه‌های خود افزونه پذیرفته می‌شود.

## توسعهٔ قواعد

فهرست دامنه‌ها در `extension/ad-domains.json` و قواعد پنهان‌سازی محافظه‌کارانه در `extension/content.js` هستند. پس از تغییر، دوباره build کنید و در صفحهٔ مدیریت افزونه Reload بزنید. قبل از اضافه‌کردن دامنه، مطمئن شوید منابع اصلی، ورود کاربر و ویدیو از آن سرو نمی‌شوند. ناوبری اصلی عمداً مسدود نمی‌شود و دامنه‌های فهرست فقط هنگام استفادهٔ شخص ثالث مسدود می‌شوند. برای استثناها اولویت بالاتر تعریف شده است.
