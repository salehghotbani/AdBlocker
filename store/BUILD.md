# Rebuild for store review

This is the source for the three store editions of AdBlocker. No minifier, bundler, remote build service or runtime third-party JavaScript library is used. Custom scripts generate local rules, channel metadata and localization; source is supplied for those steps.

## Environment

Use Node.js 20 or later and Python 3.9 or later on Linux, macOS or Windows. All build inputs, fonts and license notices are in the archive. Production packaging needs no npm installation, browser download, network connection, credential or environment secret.

From the extracted source root:

```sh
node scripts/localize.mjs --check
node scripts/store-fields.mjs --check
node scripts/build.mjs --store
python3 scripts/package.py --store
```

On Windows replace `python3` with `python`. Select `dist/stores/chrome`, `edge` or `firefox`, or the corresponding upload ZIP. `manifest.json` is at the ZIP root. Compare extracted file bytes with the submitted ZIP; ZIP timestamps/compression bytes need not match. Keep Firefox ID `adblocker@salehghotbani.local` unchanged.

`npm ci --ignore-scripts --no-audit --no-fund` is needed only for development browser tests and artwork rendering. See the root package scripts and [validation](../docs/TESTING.md). The checked-in test WebM is generated by this project; it is not downloaded YouTube media and is never shipped in an upload ZIP.

Store editions use the browser's update channel, without the manual edition's alarms, notifications or GitHub updater. Do not submit a manual-install ZIP or the entire submission kit as an extension. The reviewer source includes test drivers as readable development files; injected test-driver copies and browser profiles are excluded from upload ZIPs.
