# AdBlocker

حظر إعلانات مجاني مع تحكم بالمواقع وعدادات مباشرة دون جمع بيانات التصفح.

يفلتر AdBlocker محليًا طلبات الإعلان والتتبع المدرجة والمواضع الإعلانية المحددة. يوفر تحكمًا عامًا وبالموقع والرابط الدقيق، وإيقافًا لمرة واحدة، وعدادات منفصلة ومظهرًا فاتحًا وداكنًا. الإنجليزية افتراضية ويمكن اختيار لغة الواجهة من النافذة. كل ميزات الحظر مجانية دون حساب أو اشتراك؛ الدعم اختياري. تبقى الإعدادات والاستثناءات محلية، ولا يُجمع سجل التصفح أو محتوى النماذج. يدير المتصفح تحديثات المتجر. التغطية محددة وليست شاملة؛ قد تبقى إعلانات وتلزم استثناءات. تغييرات الحماية تعيد تحميل الصفحة تلقائيًا وانتهاء الإيقاف غير متزامن. التصفح الخاص غير مدعوم.
