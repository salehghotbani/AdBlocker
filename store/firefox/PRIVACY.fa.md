# حریم خصوصی AdBlocker — Mozilla Firefox

نسخهٔ ۱.۷.۰ فروشگاهی AdBlocker رایگان است و حساب، اشتراک، تحلیل‌گر یا درگاه پرداخت تعبیه‌شده ندارد.

- فیلتر شبکه و پنهان‌سازی جایگاه‌ها در مرورگر انجام می‌شود؛ افزونه تاریخچه، متن صفحه، اطلاعات ورود یا فرم‌ها را جمع‌آوری و ارسال نمی‌کند.
- تنظیمات، رنگ‌بندی و استثناهای انتخاب‌شده در حافظهٔ محلی مرورگر ذخیره می‌شوند. URL انتخاب‌شده ممکن است query حساس داشته باشد. شناسهٔ تب و URL توقف یک‌باره موقتاً در حافظهٔ session نگهداری می‌شوند و با بارگذاری بعدی، ناوبری، بستن تب یا مرورگر پایان می‌یابند.
- شمارنده‌ها محلی‌اند؛ تاریخچهٔ شمارش یا درخواست‌ها ذخیره و ارسال نمی‌شود. پیام صفحه فقط وضعیت مؤثر محافظت را دریافت می‌کند.
- انتخاب زبان و رنگ‌بندی محلی ذخیره می‌شوند. ترجمه‌ها و فونت‌های Shabnam و Inter داخل بسته‌اند و سرویس خارجی ندارند. مرور خصوصی در manifest غیرفعال و پشتیبانی‌نشده است.
- به‌روزرسانی را خود فروشگاه مرورگر انجام می‌دهد؛ نسخهٔ فروشگاهی درخواست انتشار GitHub، زمان‌بندی یا اعلان آپدیت ندارد و کد یا فیلتر خارجی دریافت نمی‌کند. اتصال شبکهٔ صفحات افزونه با CSP مسدود است.
- صفحهٔ حمایت محلی است. فقط اگر دریافت‌کننده تنظیم شده باشد، آدرس عمومی یا لینک HTTPS نمایش داده می‌شود. کپی آدرس فقط پس از کلیک در clipboard می‌نویسد؛ clipboard خوانده نمی‌شود. اتصال کیف پول، امضا، ارسال تراکنش، تشخیص پرداخت و ثبت مبلغ وجود ندارد. تراکنش عمومی زنجیره ممکن است برای دیگران قابل مشاهده باشد. سرویس خارجی سیاست خود را دارد.
- لینک سورس و گزارش مشکل فقط با کلیک به GitHub باز می‌شوند و آن سایت اطلاعات عادی اتصال را طبق سیاست خود می‌بیند.

مجوزهای نسخهٔ فروشگاهی: `storage`، `declarativeNetRequest`، `activeTab`، `webNavigation` و دسترسی صفحات HTTP/HTTPS برای فیلتر. مجوز اعلان، زمان‌بندی، جریان درخواست، کیف پول یا خواندن clipboard ندارد.

برای حذف داده‌ها استثناها را پاک یا افزونه را حذف کنید. برای پشتیبانی از [Issues](https://github.com/salehghotbani/AdBlocker/issues) و برای گزارش خصوصی امنیت از بخش Security مخزن استفاده کنید. اطلاعات خصوصی یا عبارت بازیابی را منتشر نکنید.

در صفحات پشتیبانی‌شدهٔ YouTube، اسکریپت ایزوله وضعیت موقت رسانه و رابط تبلیغ را محلی بررسی می‌کند تا تبلیغ پنهان/بی‌صدا شود، Skip استفاده و تنظیمات پخش بازگردانده شود. شناسهٔ موقت رسانه فقط در حافظه است و افزونه آن را ثبت یا ارسال نمی‌کند. خود YouTube می‌تواند تغییرات DOM و رسانه را ببیند.
