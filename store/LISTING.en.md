# Store listing — English (default)

## Name

AdBlocker — Browse without ads

## Short description

Free ad blocking with site controls, live counters and no browsing-data collection.

## Full description

Make more room for the content you came to read. AdBlocker is a free, open-source extension with local filters for listed advertising/tracking requests and marked ad placements.

Use simple controls to enable protection globally, exclude a site, save an exact-URL exception or pause once. The interface turns gray when protection is off on the current page. Light and dark themes are included, along with ten selectable interface languages. Persian/Arabic use bundled Shabnam and Latin scripts use bundled Inter. Private browsing is not supported.

See separate per-page counts for blocked requests and currently hidden main-document ad placements. Nested placements count once. Several requests can belong to one ad, so the two numbers are not added into a unique-ad total. Some browser contexts do not expose native request counts; unavailable values show a dash.

Filtering runs locally in the browser. AdBlocker does not collect browsing history, page text or form contents. Settings and user-selected exceptions stay in browser-local storage. No account, subscription or payment is required, and every blocking feature is free. Optional voluntary support does not unlock features or change filtering decisions.

Store editions receive updates through the browser's store. They do not fetch GitHub releases or ask you to install a ZIP manually.

Coverage is targeted, not universal. Some first-party promotions, video ads and site-specific layouts may remain. Use exceptions if a page breaks, and report a public URL through the support link so filters can be improved. Protection changes reload the current page automatically. A one-time pause expires asynchronously on the next reload or navigation; very early requests can race expiry.
